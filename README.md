# 🎲 Jogo do Número Secreto

## 📖 Sobre
Projeto de estudo prático do curso "Git e GitHub: compartilhando e colaborando em projetos" (Alura). O jogo sorteia um número aleatório e o jogador tenta adivinhar através de tentativas, recebendo dicas se o palpite é maior ou menor que o número secreto.

## 🚀 Tecnologias
- HTML5
- CSS3
- JavaScript

## ⚙️ Funcionalidades
- Número secreto sorteado dinamicamente entre 1 e o limite configurado (`numeroLimite`)
- Contador de tentativas
- Feedback de "maior" ou "menor" a cada chute
- Botão de reiniciar jogo
- Suporte a voz (responsiveVoice) para leitura das mensagens em tela
